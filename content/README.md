# Content Folders

One folder per ISO week: `YYYY-W##`

Each week has two slots:
- `01-tue-hiring/` — Tuesday 9:00 AM PST (1:00 AM Wed Manila)
- `02-fri-hiring/` — Friday 9:00 AM PST (1:00 AM Sat Manila)

Each slot:
```
brief.md      ← fill in job role, location, requirements before running produce-post
raw/          ← optional photo assets
drafts/       ← draft.json, caption.md, hashtags.md written here after produce-post
approved/     ← move approved files here at D-1
```

Copy `_template/` to start a new week.
